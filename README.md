# Selenium Java The Internet Automation

Automation practice project using:

- Java
- Selenium WebDriver
- TestNG
- Maven
- GitHub
  
Built using the Page Object Model (POM) design pattern with TestNG and Maven.

## Website Tested

https://the-internet.herokuapp.com/

## Automated Scenarios

- Browser Launch
- Valid Login
- Checkbox Selection
- Dropdown Selection
- JavaScript Alert Handling
- Dynamic Loading (Explicit Wait)
